# NP MKT 유지보수·Ship Confirm·AP 전표 관리 설계서

작성일: 2026-09-11  
상태: 구현 전 확정 설계

## 1. 범위

첨부된 `AP전표 리스트 및 계약관리(3).xlsm`을 기준으로 다음 업무를 웹 시스템으로 전환한다.

- 유지보수 계약과 업체 정보 관리
- 발주 후 Ship Confirm 및 부분 출고 관리
- 월별 유지보수 지급 대상 생성
- 인수증·인보이스·AP 전표 처리 단계 관리
- 계약 만료 알림 및 처리 이력 관리
- Excel 원본 업로드와 기존 데이터 갱신

VBA는 실행하지 않으며, 필요한 계산·상태 변경·알림 기능은 웹 기능으로 대체한다.

## 2. 핵심 데이터 구조

### 2.1 유지보수 계약

| 필드 | 필수 | 설명 |
|---|---:|---|
| maintenance_id | 자동 | 시스템 내부 ID |
| po_number | 예 | 구매 PO 번호 |
| contract_id | 예 | 계약 ID |
| contract_key | 자동 | `PO 번호 + 계약 ID` 중복 방지 키 |
| supplier_id | 예 | 표준 업체 ID |
| supplier_name | 예 | 표준 업체명 |
| customer_name | 예 | 고객명 |
| product_name | 예 | 유지보수 제품명 |
| description | 아니오 | 계약·제품 상세 설명 |
| contract_type | 아니오 | Contract/BPO 등 처리 유형 |
| sales_type | 아니오 | 판매형태 |
| contract_start_date | 예 | 계약 시작일 |
| contract_end_date | 예 | 계약 종료일 |
| customer_contract_end_date | 아니오 | 고객 계약 만료일 |
| payment_cycle | 예 | 매월/분기/일괄 등 |
| payment_months | 예 | 지급월도 목록 |
| currency | 예 | KRW/USD/EUR/JPY/CNY |
| exchange_rate | 통화별 | 사용자가 입력하는 환율 |
| amount_excl_vat | 예 | VAT 별도 금액 |
| amount_incl_vat | 자동 | VAT 포함 금액 |
| monthly_amount | 아니오 | 월별 지급 금액 |
| total_contract_amount | 아니오 | 계약 전체 금액 |
| maintenance_eligible | 자동/수정 | 유지보수 지급 대상 여부 |
| payment_exclusion_reason | 조건부 | 지급 제외 사유 |
| owner_buyer | 예 | 담당 Buyer |
| memo | 아니오 | 비고 |

`amount_incl_vat`는 원화·외화 모두 VAT 별도 금액을 기준으로 자동 계산한다. 원화 환산이 필요한 경우 사용자가 입력한 환율을 적용한다.

### 2.2 Ship Confirm 및 부분 출고

부분 출고를 지원하기 위해 하나의 PO에 여러 행을 허용한다.

| 필드 | 설명 |
|---|---|
| shipment_id | 출고 행 ID |
| maintenance_id | 유지보수 계약 연결 ID |
| po_number | PO 번호 |
| order_number | 주문번호 |
| item_code | 품목코드 |
| quantity | 출고 수량 |
| unit_price | 단가 |
| amount | 수량 × 단가 |
| serial_number | 시리얼번호 |
| received_date | 입고일 |
| delivery_place | 납품처 |
| assignee | 담당자 |
| shipment_status | 발주완료/출고대기/쉽컨펌 완료 |
| memo | 비고 |

### 2.3 지급 및 AP 전표

지급 대상은 매월 20일 기준으로 생성한다. 무상 기간 또는 지급 제외 건은 지급 대상에서 생성하지 않는다.

| 필드 | 설명 |
|---|---|
| payment_id | 지급 건 ID |
| maintenance_id | 계약 연결 ID |
| payment_month | 지급월 |
| payment_amount | VAT 별도 지급금액 |
| payment_amount_incl_vat | VAT 포함 지급금액 |
| receipt_number | 인수증 번호 |
| invoice_number | 인보이스/세금계산서 번호 |
| ap_slip_number | AP 전표번호 |
| payment_status | 아래 상태값 |
| processed_by | 처리자 |
| processed_at | 처리일시 |
| attachment_id | 증빙 파일 |
| memo | 비고 |

상태값:

`인수증 발행 → 인수증 승인 → 인보이스 발행 → 인보이스 승인 → AP 전표 완료`

| 전체 조회 | 가능 | 가능 | 가능 | 제한 조회 |
| 계약 등록·수정 | 가능 | 조회 | 가능 | 불가 |
| PO/Ship Confirm 수정 | 가능 | 조회 | 가능 | 불가 |
| 지급 상태 변경 | 가능 | 조회 | 조회/예외처리 | 불가 |
| 환율·금액 수정 | 가능 | 조회 | 가능 | 불가 |
| 만료 알림 확인 | 가능 | 가능 | 가능 | 불가 |

팀장과 관리자도 원가·지급 금액을 볼 수 있으나 요청자에게는 원가 정보를 공개하지 않는다.

## 4. 화면 설계

### 4.1 유지보수 대시보드

- 이번 달 지급 예정 건수·금액
- AP 전표 처리 단계별 건수
- 60일/30일 이내 계약 만료 건수
- Ship Confirm 미완료 건수
- 지급 제외 건수
- Buyer별 처리 현황
- 카드 클릭 시 해당 필터가 적용된 목록으로 이동

### 4.2 유지보수 계약 목록

검색 조건: PO 번호, 계약 ID, 업체명, 고객명, 제품명, Buyer, 계약 상태, 만료일, 통화, 지급월도

목록에서 계약 상세, 계약 연장 수정, Ship Confirm, 지급 일정, 변경 이력을 확인한다.

### 4.3 계약 상세

탭 구성:

1. 계약 기본정보
2. PO 및 Ship Confirm
3. 월별 지급 일정
4. 인수증·인보이스·AP 전표
5. 첨부파일
6. 변경 이력

### 4.4 Ship Confirm 화면

- PO별 출고 현황
- 부분 출고 행 추가
- 미출고 수량 자동 계산
- 시리얼번호 입력
- 입고일·납품처·담당자 입력
- 상태 변경 이력 표시

### 4.5 지급 처리 화면

- 지급월·Buyer·업체·상태별 필터
- 월별 지급 대상 자동 생성
- 인수증·인보이스·AP 전표번호 입력
- 증빙 첨부
- Buyer만 지급 상태 변경 가능
- 처리 완료 후 변경 이력 자동 저장

### 4.6 Excel 업로드 화면

업로드 순서:

1. 원본 파일 선택
2. 파일 구조 검사
3. 필수 컬럼 검사
4. PO 번호 기준 기존 행 매칭
5. 갱신 예정·신규·오류 건 미리보기
6. 업로드 확정
7. 업로드 결과 및 이력 저장

필수 컬럼 누락 시 업로드를 중단하고 누락 컬럼을 표시한다. 기존 수동 수정값은 업로드로 덮어쓰지 않는다.

## 5. 알림 규칙

- 계약 만료 D-60: 1회 발송
- 계약 만료 D-30: 1회 발송
- 수신자: 담당 Buyer
- 동일 계약·동일 기준일 알림은 중복 발송하지 않음
- 메일 발송 이력: 발송일시, 수신자, 제목, 대상 계약, 성공/실패 상태 저장

Outlook 연동 정책상 자동 발송이 제한되는 경우, 시스템에서 본문을 생성하고 복사하거나 초안 형태로 제공한다.

## 6. 갱신·중복·이력 규칙

- 기본 중복키: `PO 번호 + 계약 ID`
- 동일 키 재업로드: 기존 행 갱신
- 계약 연장: 기존 계약 수정
- 변경 전·후 값과 변경자를 이력에 저장
- PO 번호 수정은 Buyer 또는 관리자만 가능
- PO 번호 수정 시 계약 ID를 기준으로 연결 관계 유지
- 지급 완료 데이터는 삭제하지 않고 취소·정정 이력으로 관리
- 부분 출고는 기존 출고 행을 수정하지 않고 신규 행으로 추가

## 7. 개발 단계

### 1단계: 데이터·업로드 기반

- 첨부 Excel 파서
- 필수 컬럼 검증
- PO 번호 + 계약 ID 중복 처리
- 계약·업체·PO 데이터 저장
- 업로드 이력

### 2단계: Ship Confirm

- PO 목록
- 발주완료/출고대기/쉽컨펌 완료 상태
- 부분 출고 행
- 시리얼번호·입고일 관리

### 3단계: 유지보수 지급

- 매월 20일 지급 대상 생성
- 지급월도 해석
- 지급 제외 처리
- 인수증·인보이스·AP 전표 상태

### 4단계: 알림·이력·대시보드

- D-60/D-30 만료 알림
- 상태 변경·계약 변경 이력
- 카드 클릭형 대시보드
- Buyer별 처리 현황

### 5단계: Vercel·Supabase 전환

- 인증·권한
- Supabase 테이블·Storage
- 서버 배포
- Outlook 초안/복사 방식 연계

## 8. 구현 전 검증이 필요한 항목

- Excel의 VBA 매크로 결과와 웹 계산 결과 비교
- 기존 수동 수정값을 식별할 기준
- 지급월도 문장에서 추출할 수 없는 예외 건의 처리 방식
- 외화 VAT 및 환율 적용 기준
- 인수증 승인·인보이스 승인 담당자 지정 방식
- Outlook 자동 발송 제한 시 최종 사용자 업무 방식
