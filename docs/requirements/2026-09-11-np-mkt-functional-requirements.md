# NP MKT 기능별 상세 요구사항

문서 버전: v0.1  
작성일: 2026-09-11  
기준 문서: 화면 설계서 v0.1, 데이터 구조서 v0.1

## 1. 공통 요구사항

### FR-COM-01 인증·권한

- 사용자는 로그인 후 권한에 맞는 메뉴와 데이터만 조회한다.
- Excel 업로드 권한은 팀장·Buyer·관리자다.
- 업체 별칭·평가 관리는 Buyer·관리자다.
- 감사로그는 관리자만 조회한다.
- 서버/API에서 권한을 검증하며 프론트엔드 메뉴 숨김만으로 제한하지 않는다.

### FR-COM-02 FY

- 모든 기간 분석의 기본값은 현재 FY다.
- FY는 4월 1일~다음 해 3월 31일이다.
- 기준일은 세금계산서날짜다.
- 사용자는 FY 또는 사용자 지정 기간을 선택할 수 있다.

### FR-COM-03 표시·추적성

- 금액은 원 단위 천 단위 구분, 비율은 소수점 1자리로 표시한다.
- 분석 결과에서 원본 행 번호·PO번호·업로드 배치를 확인할 수 있다.
- 빈값은 `미입력`, 계산 불가값은 `미표시`, 검토 대상은 `확인 필요`로 표시한다.

## 2. Excel 업로드·누적 갱신

### FR-IMP-01 파일 선택

- 원본 xlsx/xlsm 파일 전체를 선택할 수 있다.
- 파일당 최대 10MB다.
- `CD집계표(Total)` 시트를 대상으로 한다.
- 헤더는 4행을 기준으로 한다.
- 업로드자는 팀장·Buyer·관리자만 가능하다.

### FR-IMP-02 필수 컬럼 검증

- 필수 컬럼이 누락되면 전체 업로드를 중단한다.
- 누락 컬럼명과 원본 파일에서 기대하는 컬럼명을 표시한다.
- 필수 컬럼 기준은 PO 번호, 세금계산서날짜, 수량, 단가(원), 금액(원), 납품업체명, 모델명, Sub Category 1, Sub Category 3, Cost Down 금액, C/D%다.
- 단순 데이터 빈값과 컬럼 자체 누락은 구분한다.

### FR-IMP-03 행 검증

- 날짜·금액·수량은 형식 검증을 한다.
- PO번호 빈값은 저장을 허용하고 `PO번호 누락` 경고를 생성한다.
- 수량×단가와 V열 금액 차이는 원본값을 유지하고 검증 결과로 표시한다.
- 업체명·카테고리 자동 매칭 실패는 경고로 표시한다.
- 오류 행·경고 행·정상 행 수를 미리보기에서 보여준다.

### FR-IMP-04 누적·갱신

- 유효한 PO번호를 갱신 키로 사용한다.
- 기존 PO와 일치하면 새 파일의 최신 내용으로 갱신한다.
- 신규 PO는 새 구매 건으로 추가한다.
- 동일 PO의 여러 행은 하나의 구매 건과 여러 품목으로 저장한다.
- 새 파일에 없는 기존 PO는 삭제하지 않는다.
- 빈 PO번호 행은 기존 행과 자동 매칭하지 않는다.
- 반영 전 신규·갱신·경고 건수 미리보기를 제공한다.
- 반영 결과를 배치 ID로 저장한다.

### FR-IMP-05 업로드 이력

- 파일명, 크기, 업로드자, 일시, 대상 시트, 처리 상태를 저장한다.
- 전체·신규·갱신·경고·오류 행 수를 저장한다.
- 오류·경고 행을 원본 행 번호와 함께 조회한다.
- 월별 업로드 이력을 검색·다운로드할 수 있다.

### FR-IMP-06 PO번호 보완

- 빈 PO번호 행 목록을 제공한다.
- 팀장·Buyer·관리자가 PO번호를 직접 입력·수정한다.
- 저장 시 기존 PO 중복 여부를 재검사한다.
- 중복이면 저장하지 않고 기존 PO 정보를 표시한다.
- 정상 입력되면 `PO번호 누락` 상태를 해제하고 수정 이력을 남긴다.

## 3. 구매 이력 분석

### FR-HIS-01 검색·필터

- FY, 기간, PO번호, 모델명, 대분류, 소분류, Buyer, 업체, 구매용도로 검색한다.
- 필터 조합 결과를 표와 요약 카드로 표시한다.
- 검색 결과를 Excel로 다운로드할 수 있다.

### FR-HIS-02 상세 근거

- 원본 행 번호, 원본 파일명, 업로드 배치, 품목·금액·Cost Down을 표시한다.
- 정규화 업체명·카테고리와 원본값을 함께 확인할 수 있다.

## 4. 구매 현황 대시보드

### FR-DASH-01 KPI

- 전체 구매금액, 구매 건수, Cost Down 금액, 절감률, 만기 임박 계약, 최근 업로드 상태를 제공한다.
- 구매금액은 V열 금액 합계를 사용한다.
- 카드 클릭 시 해당 상세 분석 화면으로 이동한다.

### FR-DASH-02 차트

- 월별 구매금액 추이
- 대분류·소분류별 구매금액
- Buyer별 구매금액·건수
- 업체별 구매금액
- 구매용도별 구매금액
- Cost Down 월별 추이

차트 항목 클릭 시 필터를 적용한 근거 표를 제공한다.

## 5. 비용 분석

### FR-COST-01 금액 분석

- FY·월별 구매금액을 집계한다.
- 대분류·소분류·Buyer·업체·구매용도·Cost center·계정별로 집계한다.
- 금액·건수·평균 단가·단가 분포를 제공한다.

### FR-COST-02 금액 검증

- `수량×단가`와 V열 금액을 비교한다.
- 차이 금액과 차이 발생 행을 제공한다.
- 원본 구매금액은 자동 수정하지 않는다.

## 6. Cost Down 분석

### FR-CD-01 공식값

- Cost Down 금액은 AS열 값을 사용한다.
- 절감률은 AT열 값을 사용한다.
- 총 C/D단가·최대견적가는 분석 보조로 사용한다.

### FR-CD-02 분석 결과

- 월별·FY별 절감액·절감률
- 대분류·소분류별 절감액·절감률
- Buyer별 절감액·절감률
- 업체별 절감액·절감률
- 구매금액 대비 Cost Down 비율
- 절감액·절감률 순위

모든 차트는 원본 근거 행을 제공한다.

## 7. 업체 분석·추천

### FR-SUP-01 업체 표준화

- 원본 업체명을 정규화한다.
- 대표 업체와 별칭을 연결한다.
- 별칭은 화면에서 추가·수정·해제할 수 있다.
- 사업자번호가 있으면 매칭 보조키로 사용한다.
- 자동 매칭이 불확실하면 `검토 필요`로 표시한다.

### FR-SUP-02 업체 분석

- 업체별 구매 건수·금액·평균 단가를 제공한다.
- 업체별 Cost Down 금액·절감률을 제공한다.
- 거래 횟수·최근 거래일·주요 카테고리를 제공한다.
- 유지보수 구매 이력이 있으면 유지보수 가능 여부를 자동으로 `가능` 처리한다.

### FR-SUP-03 업체 평가

- 추후 업체 평가 파일을 업로드한다.
- 업체명 별칭을 사용해 기존 업체와 연결한다.
- 평가 기간과 평가 항목별 점수를 보존한다.
- 평가 파일 구조가 맞지 않으면 반영하지 않고 오류를 표시한다.

### FR-SUP-04 추천 점수

- 가격 경쟁력 40%
- 업체 평가 30%
- 유지보수 가능 여부 15%
- 거래 안정성 15%

추천 결과는 추천 업체·신규 업체·평가 미등록·가격 비교 불가·Buyer 검토 필요 영역으로 구분한다.

신규 업체는 과거 거래 없이 업체 마스터 또는 평가 파일에만 존재하는 업체다.

## 8. 예상 단가

### FR-PRICE-01 동일 모델 검색

- 정규화 모델명을 기준으로 과거 거래를 검색한다.
- 대분류·소분류·규격이 다른 경우 별도 모델로 구분한다.

### FR-PRICE-02 단가 지표

- 최저 단가
- 평균 단가
- 최근 단가
- 최근 세금계산서날짜
- 최근 업체
- 과거 거래 건수

결과에는 계산에 사용된 원본 근거 행을 포함한다.

## 9. 견적 요청 메일

### FR-MAIL-01 초안 생성

- 업체 담당자를 수신자로 자동 입력한다.
- 요청자의 조직 팀장을 참조자로 자동 입력한다.
- 구매요청번호·PO번호·고객명·모델명·수량·납품월·납품주소를 본문에 넣는다.
- 회신 희망일과 견적 요청 문구를 제공한다.
- 관련 첨부파일을 선택할 수 있다.

### FR-MAIL-02 작성·복사

- 제목·본문을 화면에서 수정할 수 있다.
- 미리보기를 제공한다.
- 본문을 클립보드로 복사할 수 있다.
- 초안과 복사 이력을 저장한다.
- 실제 Outlook 발송은 본 범위에서 제외한다.

## 10. 이메일 이력

### FR-MAIL-LOG-01 이력

- 작성일시·작성자·업체·수신자·참조자·제목을 저장한다.
- 생성·복사 완료·발송 예정·실패 상태를 구분한다.
- 당시 본문 스냅샷과 원가 마스킹 여부를 저장한다.
- 구매 건·PO번호로 이력을 검색한다.

## 11. AI 자연어 검색

### FR-AI-01 질문 해석

- 구매 이력·구매금액·단가·업체·Buyer·구매용도·대분류·소분류·Cost Down·업로드 이력을 검색한다.
- 예시 질문:
  - 올해 네트워크 구매금액이 가장 큰 업체는?
  - 김희균 Buyer의 5월 Cost Down 금액은?
  - 작년 서버 구매 평균 단가와 최근 단가를 비교해줘.

### FR-AI-02 답변 구성

- 자연어 요약 답변
- 차트
- 적용된 기간·필터
- 원본 근거 행
- 답변 생성 시각

### FR-AI-03 검색 이력

- 사용자·질문·해석 의도·필터·답변·차트 설정을 저장한다.
- 근거 레코드와 검색 당시 값 스냅샷을 저장한다.
- 사용자가 과거 검색 결과를 다시 열 수 있다.

## 12. 계약·월별 지불

### FR-CON-01 계약

- 업체·제품·계약유형·기간·청구주기·금액·Buyer·유지보수 여부·첨부파일을 관리한다.
- 계약 만기 90·60·30일·만료 상태를 계산한다.

### FR-CON-02 지불대상

- 매월 20일 기준으로 해당 월 지불 후보를 생성한다.
- 예정·자료요청·검토중·완료 상태를 제공한다.
- 만기 알림 수신자는 해당 Buyer다.

## 13. 첨부파일

### FR-FILE-01 업로드

- 요청·품목·계약·업로드 배치에 파일을 연결한다.
- 파일당 최대 10MB다.
- 비공개 저장소와 만료형 URL을 사용한다.
- 삭제는 기본적으로 논리 삭제한다.

## 14. 감사로그

### FR-AUDIT-01 기록 대상

- 업로드·갱신·PO번호 보완
- 업체 별칭·평가 변경
- Buyer·카테고리 매핑 변경
- 민감 가격 열람
- 메일 초안 생성·복사
- AI 검색
- 관리자 예외 처리

각 로그는 수행자·대상·변경 전·변경 후·사유·일시를 저장한다.

## 15. 기능 완료 기준

- 요구 기능을 정상·빈값·중복·권한 오류 조건에서 검증한다.
- Excel 업로드는 필수 컬럼 누락 시 저장하지 않는다.
- 빈 PO번호는 저장되지만 경고와 보완 입력이 가능하다.
- PO 갱신·신규 누적·기존 데이터 보존이 모두 재현된다.
- 모든 분석 결과에서 원본 근거 행을 추적할 수 있다.
- AI 결과는 차트와 근거 행을 함께 제공한다.
- 모든 주요 변경과 민감 조회가 감사로그에 남는다.
