# NP MKT CD분석 시스템 화면 설계서

문서 버전: v0.1  
작성일: 2026-09-11  
목적: CD집계표 기반 분석 시스템의 화면 구성과 사용자 흐름 정의

## 1. 화면 설계 원칙

- 모든 분석의 기본 기간은 현재 FY(4월 1일~다음 해 3월 31일)다.
- 원본값과 정규화값을 구분해 표시한다.
- 표·차트·근거 행을 연결해 분석 결과를 추적할 수 있게 한다.
- 업로드 결과는 저장 전 미리보기와 오류·경고 요약을 제공한다.
- 민트 그린 중심의 기존 NP MKT 무드보드 UI를 사용한다.
- 팀장·Buyer·관리자 중심의 내부 업무 화면으로 설계한다.

## 4. 상세 화면 설계

### S-01 로그인

구성:

- 회사 이메일
- 비밀번호
- 로그인 버튼
- 로그인 실패 메시지
- 계정 정책 안내

운영에서는 회사 계정 또는 승인된 사내 인증을 사용한다. 로컬 프로토타입에서는 테스트 계정을 제공한다.

### S-02 대시보드

상단 KPI 카드:

- 전체 구매금액
- 구매 건수
- Cost Down 금액
- Cost Down 절감률
- 만기 임박 계약
- 최근 업로드 상태

주요 차트:

- 월별 구매금액 추이
- 대분류·소분류별 구매금액
- Buyer별 구매금액·구매 건수
- 업체별 구매금액
- 구매용도별 구매금액
- 월별 Cost Down 추이
- 대분류·Buyer별 Cost Down

상호작용:

- 카드 클릭 시 해당 필터가 적용된 상세 목록으로 이동
- 차트 항목 클릭 시 해당 대분류·소분류·Buyer·업체 필터 적용
- 차트에 마우스를 올리면 금액·건수·비중 표시
- 원본 근거 행 보기 버튼 제공

### S-03 구매 이력

검색 결과 컬럼:

- 세금계산서날짜
- PO번호
- Buyer
- 업체명
- 모델명
- 대분류·소분류
- 구매용도
- 수량
- 단가
- 구매금액
- Cost Down 금액·절감률
- 데이터 품질 경고

상세 패널:

- 원본 행 번호와 업로드 배치
- 품목별 상세
- 견적 비교
- 금액 검증값
- 업체 별칭 연결 상태
- 원본 파일 근거

### S-04 Cost Down 분석

KPI:

- 총 Cost Down 금액
- 평균 절감률
- 구매금액 대비 절감률
- 전월·전년 대비 변화

분석 탭:

1. 월별 추이
2. 대분류별
3. 소분류별
4. Buyer별
5. 업체별

각 차트에서 선택한 값은 하단 근거 표에 즉시 반영한다.

### S-05 비용 분석

- FY·월별 구매금액
- 대분류·소분류별 구매금액
- Buyer·업체·구매용도별 구매금액
- 모델별 단가 분포
- 수량×단가와 V열 금액 차이
- Cost center·계정별 비용

공식 구매금액은 V열 금액을 사용하고, 계산금액과의 차이는 검증용으로 표시한다.

### S-06 업체 분석·추천

업체 분석 카드:

- 대표 업체명·별칭
- 구매 건수·구매금액
- Cost Down 금액·절감률
- 평균 단가
- 유지보수 가능 여부
- 업체 평가점수
- 거래 안정성

추천 영역:

- 추천 업체
- 신규 업체
- 평가 미등록
- 가격 비교 불가
- Buyer 검토 필요

추천 점수 비중:

- 가격 경쟁력 40%
- 업체 평가 30%
- 유지보수 가능 여부 15%
- 거래 안정성 15%

### S-07 예상 단가

검색 조건:

- 모델명
- 대분류·소분류
- 기간
- 업체

결과:

- 최저 단가
- 평균 단가
- 최근 단가
- 최근 구매일
- 최근 업체
- 과거 거래 건수
- 원본 근거 행

동일 모델은 정규화 모델명을 기준으로 묶고, 규격이 다른 경우 별도 모델로 분리한다.

### S-08 견적메일 초안

입력·자동 생성 항목:

- 업체 담당자 수신
- 팀장 참조
- 제목
- 구매요청번호·PO번호
- 고객명
- 모델명·수량
- 희망 납품월
- 납품주소
- 회신 희망일
- 견적 요청 문구
- 첨부파일

버튼:

- 초안 생성
- 미리보기
- 본문 복사
- 저장
- 초기화

실제 메일 발송은 이 범위에서 제외한다.

### S-09 이메일 이력

- 작성일시
- 작성자
- 업체
- 수신자·참조자
- 제목
- 상태: 초안·복사 완료·발송 예정·실패
- 본문 보기
- 관련 구매 건

### S-10 Excel 업로드

단계 표시:

1. 파일 선택
2. 파일·시트 검사
3. 컬럼·행 검증
4. 신규·갱신·경고 미리보기
5. 반영
6. 결과

검증:

- 파일당 10MB 이하
- `CD집계표(Total)` 시트 존재
- 헤더 4행 및 필수 컬럼 확인
- 날짜·금액·수량 형식 확인
- PO번호 중복·빈값 확인
- 업체명·카테고리 매칭 확인

빈 PO번호는 저장 허용 후 경고한다. 필수 컬럼 누락은 저장하지 않고 누락 컬럼을 표시한다.

### S-11 업로드 이력

- 파일명·업로드일시·업로드자
- 전체 행·신규·갱신·경고·오류 건수
- PO번호 누락 건수
- 업체명 매칭 필요 건수
- 반영 상태
- 오류 행 다운로드
- 배치 상세 보기

### S-12 업체 관리

탭:

1. 업체 목록
2. 업체명 별칭
3. 담당자
4. 유지보수 가능 여부
5. 업체 평가
6. 신규 업체

업체명 별칭은 대표 업체에 연결·해제할 수 있다.

### S-13 카테고리 관리

- Main Category
- 대분류(Sub Category 1)
- 소분류(Sub Category 3)
- Buyer 매핑
- 중복 매핑 경고
- 적용기간
- 활성 여부

중복 매핑은 `Buyer 결정 필요`로 표시하고 관리자가 최종 매핑을 확정한다.

### S-14 시스템 설정

- 사용자·역할
- FY 시작월
- 금액 검증 허용 오차
- 업체 추천 점수 비중
- AI 검색 정책
- 메일 템플릿
- 파일 확장자·용량 정책

## 5. 주요 화면 흐름

```text
로그인
  ↓
대시보드
  ├─ KPI/차트 클릭 → 구매 이력·Cost Down·비용 분석
  ├─ 업체 클릭 → 업체 분석·추천
  ├─ 모델 클릭 → 예상 단가
  └─ 업로드 알림 → 업로드 이력 상세

Excel 업로드
  ↓ 검증
미리보기
  ├─ 오류 → 수정 후 재업로드
  └─ 정상/경고 → 반영
        ↓
대시보드·분석 갱신
```

## 6. 반응형·표시 규칙

- 데스크톱 우선 내부 업무 화면
- 차트는 최소 1024px 폭 기준으로 설계
- 표는 가로 스크롤 허용
- 금액은 원 단위 천 단위 구분
- 백분율은 소수점 1자리
- 빈값은 `미입력`, 계산 불가값은 `미표시`, 검토 대상은 `확인 필요`로 표시
- 오류는 빨간색, 경고는 노란색, 정상은 민트색으로 구분

## 7. 확인 필요 화면 정책

다음은 구현 전 최종 확정이 필요한 화면 정책이다.

1. 동일 PO의 일부 품목만 새 파일에 있을 때 품목 삭제·유지 방식
2. 금액 불일치 허용 오차
3. 업체 평가 파일 실제 컬럼
4. 팀장 이메일 자동 조회 방식
5. AI 검색 데이터 외부 전송 허용 범위
