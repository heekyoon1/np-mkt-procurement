# NP MKT 구매 인텔리전스 시스템 팀 공유 스토리보드

목적: 현재 구현물을 팀에 공유하고, 사용 시나리오와 운영 전 전환 과제를 합의한다.

공유 대상: NP MKT 팀장, Buyer, 구매요청 부서, 시스템 운영 담당자

권장 소요 시간: 12~15분

## 1. 핵심 메시지

기존 엑셀 중심 구매 데이터를 업로드하면, 구매 이력·Cost Down·단가·업체·구매 예측을 한 화면에서 분석하고 근거 행까지 확인할 수 있다. 현재는 **업무 검증용 웹 프로토타입**이며, 팀 검토 후 Supabase 기반의 공유 운영 시스템으로 전환한다.

## 2. 발표 흐름

| 순서 | 화면/장면 | 시연 내용 | 전달할 메시지 | 시간 |
|---|---|---|---|---|
| 1 | 도입 | 엑셀·구매 ON·계약 관리 파일이 분리된 현재 업무를 설명 | 데이터 확인과 반복 보고에 드는 시간을 줄인다. | 1분 |
| 2 | 목표 | “요청 → 구매 분석 → Cost Down → 예측 → 계약·지불” 흐름 제시 | 구매 처리와 의사결정에 같은 데이터를 사용한다. | 1분 |
| 3 | 로그인/권한 | 요청자·팀장·Buyer·관리자 역할 선택 화면 | 원가는 Buyer와 팀장 승인 화면에서만 보이도록 설계했다. | 1분 |
| 4 | 구매요청 | 요청 등록, 팀장 승인, Buyer 상태 변경 흐름 | 상태는 접수/구매진행 → 견적완료 → 발주중 → 쉽컴펌 완료로 관리한다. | 1분 |
| 5 | CD 업로드 | `CD집계표(Total)` 원본 업로드, PO번호 기준 갱신 및 누락 경고 확인 | 완료 구매 이력을 매월 업로드해 누적 분석한다. | 2분 |
| 6 | 구매 분석 | FY·Buyer·대분류 조건으로 조회하고 구매금액 카드 클릭 | 카드와 차트에서 즉시 근거 행 목록으로 이동한다. | 1분 |
| 7 | Cost Down | 절감액·절감률·구매금액·절감 발생 건수 카드와 근거 행 확인 | 절감액, 절감률, 월·Buyer·카테고리별 성과를 같은 기준으로 본다. | 2분 |
| 8 | 단가·업체 분석 | 동일 모델의 최저·평균·최근 단가, 업체별 거래금액 확인 | 견적 전 과거 거래 단가와 업체 실적을 빠르게 비교한다. | 1분 |
| 9 | 업체 추천/견적 메일 | 카테고리별 추천 업체와 견적 요청 메일 초안 생성·복사 | 업체 평가는 다음 단계에서 반영하며, 현재는 거래·가격·유지보수 이력 기반이다. | 1분 |
| 10 | AI 자연어 검색 | 예시 질문으로 결과와 근거 행 확인 | 자연어 질문도 현재 업로드 데이터에서 계산하고 근거를 보여준다. | 1분 |
| 11 | 예측·사업기회 | 반복 구매·다음 달 구매금액·절감 기회 화면 | 예측은 의사결정 보조이며 Buyer 검토 후 요청 초안으로 전환한다. | 1분 |
| 12 | 계약·지불관리 | 유지보수 지불대상, Ship Confirm, 계약 목록 순서로 확인 | AP/계약 파일의 핵심 상태와 지급 대상을 웹에서 조회·관리한다. | 1분 |
| 13 | 전환 계획 | 현재 프로토타입과 운영화 범위를 구분 | 팀 검토 후 데이터 공유·인증·첨부·메일 연동을 운영 수준으로 전환한다. | 1분 |

## 3. 시연 준비

1. Buyer 역할로 로그인한다.
2. `CD 업로드`에서 최신 CD집계표를 업로드한다.
3. 업로드 결과의 전체·신규·갱신·PO 누락 건수를 확인한다.
4. `Cost Down`, `구매 분석`, `AI 검색` 순서로 이동해 실제 값과 근거 행을 보여준다.
5. 계약·지불관리에서는 밝은 행 기준의 당월 지급 대상과 만료 계약 제외 기준을 설명한다.

## 4. 시연용 질문

- 올해 네트워크 구매금액이 가장 큰 업체는?
- 김희균 Buyer의 5월 Cost Down 금액은?
- 작년 서버 구매 평균 단가와 최근 단가를 비교해줘.
- 다음 달 예상 구매금액은?
- 반복 구매 30일 이내 후보는?

## 5. 현재 구현 범위

### 구현·검증 가능한 기능

- 구매요청 등록·팀장 승인·Buyer 상태 변경 데모
- 원가 비공개 규칙 및 역할별 화면 표기
- CD집계표 업로드·PO번호 기준 갱신·PO 누락 경고
- 구매 이력, 비용, Cost Down, 단가, 업체, 카테고리 분석
- 카드·진행단계 클릭 시 해당 근거 목록 이동
- 한글/영문 카테고리 검색 별칭
- 업체 추천과 Outlook용 견적 요청 메일 초안·이력
- 계약·유지보수·지불·Ship Confirm 조회 및 상태 변경 프로토타입
- 구매 예측, 반복 구매 후보, 사업기회 추천, 자연어 질의형 로컬 분석
- Vercel 배포 및 Supabase 연결 상태 확인

### 운영 전 전환이 필요한 기능

- 데이터 영구 저장: 현재 업로드 데이터와 로그인 정보는 브라우저 로컬 저장소 중심이다.
- 실제 사용자 인증·권한: Supabase Auth 또는 회사 AD 연동 정책 결정이 필요하다.
- 조직 공용 데이터: CD·계약 업로드 결과를 Supabase에 저장하고 팀원이 공통으로 조회해야 한다.
- 첨부파일: 10MB 정책에 맞춘 Supabase Storage 저장과 권한 제어가 필요하다.
- 메일 발송: Microsoft Graph 앱 등록이 불가하므로 Outlook 초안 복사 방식으로 제공 중이다.
- 업체 평가: 평가 파일 업로드 후 추천 점수에 반영해야 한다.
- 계약 파일: Ariba 입력 시트 중심의 계약·지불·Ship Confirm 파서를 완성하고 실제 데이터를 검증해야 한다.

## 6. 팀 논의 및 결정 요청

| 주제 | 팀에서 결정할 내용 | 결정 후 작업 |
|---|---|---|
| 사용자 인증 | 회사 AD 연동 가능 여부 또는 Supabase Auth 사용 여부 | 역할 기반 접근 제어 적용 |
| 역할 관리 | 팀장·Buyer·관리자 명단과 권한 승인 절차 | 실사용자 권한 등록 |
| 업로드 운영 | 월별 CD집계표 업로드 담당자와 검증 기준 | 업로드 이력·오류 처리 운영화 |
| 업체 평가 | 평가 파일 양식과 평가 항목·가중치 | 추천 업체 점수 반영 |

| 메일 | Outlook 초안 복사 유지 여부 | 메일 발송 이력 운영 기준 확정 |
