# NP MKT 개발 단계별 범위

문서 버전: v0.1  
작성일: 2026-09-11  
기준 문서: 화면 설계서 v0.1, 기능별 상세 요구사항 v0.1, 데이터 구조서 v0.1

## 1. 개발 전략

기능을 한 번에 모두 운영화하지 않고, `업로드·데이터 품질 → 분석 → 추천·메일 → AI` 순서로 개발한다. 각 단계 완료 후 사용자가 화면과 결과를 확인하고 다음 단계로 이동한다.

목표 배포 구조:

- Frontend/API: Next.js + TypeScript
- Hosting: Vercel
- Database: Supabase PostgreSQL
- File storage: Supabase Storage
- 인증: Supabase Auth 또는 회사 정책에 맞는 사내 인증
- 메일: 실제 발송 전 시스템 내 초안·복사·이력 우선

## 2. 단계 요약

| 단계 | 핵심 목표 | 사용자 확인 결과 |
|---|---|---|
| Phase 0 | 요구사항·데이터 규칙 확정 | 설계 기준 승인 |

## 13. 전체 완료 기준

- 원본 Excel을 월 1회 업로드해 기존 PO 갱신·신규 누적이 가능하다.
- 빈 PO번호를 놓치지 않고 화면에서 보완할 수 있다.
- FY·세금계산서날짜 기준 분석 결과를 확인할 수 있다.
- 구매금액·비용·Cost Down·업체·단가 분석이 원본 근거 행과 연결된다.
- 신규 업체와 기존 업체를 구분하고 추천 점수를 확인할 수 있다.
- 견적메일을 화면에서 작성·복사하고 이력을 남길 수 있다.
- AI 검색 결과에 차트와 근거 행이 포함된다.
- 역할별 접근권한과 감사로그가 동작한다.
- Vercel·Supabase Preview 환경에서 핵심 흐름을 재현한다.
